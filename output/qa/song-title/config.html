加入后点击“保存到壁纸”生效。播放时自动在线转码为 OGG 音频，需要联网及本机助手运行。无需下载整首歌曲；切歌或拖动进度后会短暂缓冲。

缩放和灵敏度自动保存并即时应用到壁纸。Wallpaper Engine 面板的改动会同步到这里；此页的改动不会反向刷新面板滑块。

点击切换：音量显示随频谱强弱起伏；波形显示本机默认输出的真实音频采样，需要新版助手运行。采样只用于实时显示，不保存音频。点击“保存到壁纸”后生效。

正在识别输出设备…

耳机模式在同一个方框内，左侧显示左声道，右侧显示右声道，不添加分隔线。此选项点击“保存到壁纸”后生效。自动模式跟随 Windows 默认输出设备；若识别不准，可手动选择左右声道。Wallpaper Engine 的音频录制设备仍需与输出设备一致。

横竖屏自动适配。空间不足时会限制尺寸，避免区域重叠。也可在 Wallpaper Engine 属性面板中调整。

保存与迁移

保存后，设置和歌单会保留在本机。导出 JSON 可备份歌单结构与显示设置。

JSON 不包含音乐文件。换设备后，请重新导入本地音乐，或使用随壁纸打包的音频路径。保存会写入当前壁纸目录的 config.json；音乐导入到 music 文件夹。
